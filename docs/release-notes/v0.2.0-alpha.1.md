> ⚠️ **Pré-lançamento de teste, só para Windows 11.** Esta versão **captura** a webcam, mas **ainda não grava vídeo**.

## O que dá para testar

- **Teste da webcam (1 min):** mede se a câmera entrega o fps prometido.
- **Teste de tela bloqueada:** descobre se o Sentinel continua vendo a câmera com o
  computador bloqueado e a tela apagada (Modern Standby). É o maior risco técnico do projeto.
- **Teste de controle:** o mesmo teste sem impedir o Windows de dormir, para comparar.

Tudo pelo **Menu Iniciar → Sentinel AI**, sem terminal e sem instalar ferramentas de
desenvolvimento. O passo a passo vem junto, em "Como testar".

## Novidades técnicas

- Captura de webcam, câmera IP (RTSP) e arquivo de vídeo, com reconexão automática.
- A câmera só aparece como "STREAMING" se a imagem estiver chegando de verdade.
- Senhas de câmeras IP no Gerenciador de Credenciais do Windows, nunca em arquivo.
- Enquanto captura, o Sentinel pede ao Windows para não dormir, de forma visível em
  `powercfg /requests`. Nenhuma configuração do sistema é alterada.
